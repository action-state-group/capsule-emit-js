# agent-action-capsule

This package is a stub that redirects to the scoped package.

**Install the real library:**

```sh
npm install @agentactioncapsule/emit
```

The scoped package `@agentactioncapsule/emit` provides the spec-pure
JavaScript/TypeScript implementation of the Agent Action Capsule
canonicalization, CPB derive_id, capsule emit, and Class 1 verify.

Source: <https://github.com/action-state-group/capsule-emit-js>
